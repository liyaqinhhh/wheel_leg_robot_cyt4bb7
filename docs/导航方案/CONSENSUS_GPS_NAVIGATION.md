## 2. 验收标准（Given-When-Then）

### M1: 航点管理

**AC-01: 航点添加**
- Given 系统已初始化且航点数 < 40
- When 调用 `gps_wp_add(lat, lng)` 添加合法坐标
- Then 航点追加到末尾，count++，返回 1

**AC-02: 航点边界**
- Given 航点数已达 40
- When 调用 `gps_wp_add(lat, lng)`
- Then 返回 0，拒绝添加

**AC-03: Flash 读写一致性**
- Given 内存中有 5 个航点
- When 调用 `gps_wp_save_to_flash()` 后重启再调用 `gps_wp_init()`
- Then 加载的 5 个航点经纬度与保存前完全一致（double 精度无损）

**AC-04: Flash 魔数校验**
- Given Flash 页 51 魔数不匹配
- When 开机调用 `gps_wp_init()`
- Then valid=0，不加载任何航点，串口报错

### M2: 导航状态机

**AC-05: 状态流转**
- Given 航点有效（≥2 个）且 turn_mode==5
- When 进入导航模式
- Then 状态按 IDLE → CALIBRATING → NAVIGATING → ARRIVED → COMPLETE 流转

**AC-06: 方位角计算**
- Given 当前位置 (30.0°N, 120.0°E)，目标航点 (30.001°N, 120.0°E)（正北约 111m）
- When 调用方位角计算
- Then 方位角 ≈ 0°（正北），距离 ≈ 111m

**AC-07: 环形低通滤波**
- Given 上次滤波值 179°，新值 -179°
- When 调用 `angle_lpf_circular()`
- Then 滤波结果在 179° 附近微调（走最短弧度 2°），而非跳到 0°

**AC-08: 到达判定（滞后）**
- Given 距离从 5m 减小到 1.5m
- When 距离 < 2m
- Then 判定到达，切换下一航点

**AC-09: 到达判定（防抖）**
- Given 已到达航点（距离 1.5m），后距离波动到 2.5m
- When 距离在 2m~3.5m 之间波动
- Then 不反复触发到达判定（滞后区间内保持到达状态）

### M3: 校准与漂移补偿

**AC-10: 起点校准（正北）**
- Given 机器人面朝正北（IMU yaw=0°），航点1→航点2 方位角=0°
- When 执行起点校准
- Then offset = 0°

**AC-11: 起点校准（45°偏移）**
- Given 机器人面朝东北（IMU yaw=0°），航点1→航点2 方位角=45°
- When 执行起点校准
- Then offset = 45°

**AC-12: 校准失败（偏移过大）**
- Given |offset| > 90°
- When 执行起点校准
- Then 校准失败，offset 保持 0，不启动导航

**AC-13: 校准失败（航点不足）**
- Given 航点数 < 2
- When 执行起点校准
- Then 校准失败，不启动导航

**AC-14: 漂移修正门控**
- Given GPS 有效 + 速度 > 5km/h + 误差 < 30°
- When 调用 `gps_cal_drift_correction()`
- Then offset 缓慢修正（α=0.02）

**AC-15: 漂移修正抑制**
- Given GPS 无效 或 速度 < 5km/h 或 误差 > 30°
- When 调用 `gps_cal_drift_correction()`
- Then offset 不修正

### M4: ISR 集成

**AC-16: 乒乓缓冲读取**
- Given 乒乓缓冲已写入 target_bearing=90°, offset=5°
- When 4ms ISR 中 turn_mode==5 读取缓冲
- Then desired_yaw = 95°，传入 Cascade_angle_Yaw_4

**AC-17: GPS 丢星超时**
- Given 导航中 GPS 丢星
- When 持续 5s 无有效 GPS 数据
- Then 保持最后方位角，不更新缓冲

### M5: 按键交互

**AC-18: 按键采点**
- Given GPS 信号有效（gnss.state==1）
- When 按下采点按键
- Then 当前 GPS 坐标添加为航点

### M6: 显示

**AC-19: 导航状态显示**
- Given 导航运行中
- When IPS200 刷新
- Then 显示当前状态、目标航点索引、距离、方位角

## 3. 约束与边界确认

### 3.1 硬件约束

| 约束 | 值 | 说明 |
|------|-----|------|
| MCU | CYT4BB7 (Cortex-M7 @ 250MHz) | 硬件 FPU |
| IMU | IMU660RA | 1kHz 采样，EKF/Kalman 滤波 |
| GNSS | TAU1201 (UART2) | 10Hz NMEA 输出 |
| Flash | Work Flash 192KB, 2KB/页 | GPS 使用页 50/51 |
| 显示 | IPS200 | SPI 接口 |

### 3.2 软件约束

| 约束 | 值 | 说明 |
|------|-----|------|
| 编码格式 | GBK | 项目统一编码，所有 .c/.h 文件 |
| 最大航点数 | 40 | 每航点 16 字节，1 页 Flash 足够 |
| Flash 页分配 | 页 50（数据）+ 页 51（元数据） | 避开现有分区 |
| 导航计算频率 | 10Hz（main while 循环） | 不在 ISR 中执行 |
| PID 执行频率 | 250Hz（4ms ISR） | Cascade_angle_Yaw_4 |
| 乒乓缓冲大小 | 2 个快照 | 写入方和读取方各持一个 |

### 3.3 已知限制（不实现）

| 限制 | 说明 | 理由 |
|------|------|------|
| 无 GPS 信号时不导航 | 不实现纯 IMU 推算 | 复杂度高，需求未要求 |
| 不支持转弯半径感知 | 简单原地转向 | 需求明确为简单直线转弯 |
| 不支持中途修改航点 | 需重新采点 | 简化实现 |
| 不支持多路线 | 单次路线导航 | 需求未要求 |
| IMU 长时间漂移 | >5 分钟精度下降 | 有漂移修正但非完美 |

### 3.4 Flash 分区表

| 页 | 使用者 | 用途 | GPS 冲突 |
|----|--------|------|----------|
| 0 | Ins.c | INS 数据 | 无 |
| 1 | — | — | 无 |
| 10 | Ins.c | INS 元数据 | 无 |
| 25-26 | ins_track | 轨迹数据 | 无 |
| 27-49 | ins_segment | 段导航 | 无 |
| **50** | **GPS 导航** | **航点数据** | — |
| **51** | **GPS 导航** | **航点元数据** | — |

## 4. 关键决策确认

| # | 决策项 | 选项 | 结论 | 理由 |
|---|--------|------|------|------|
| D1 | 转弯策略 | A. 半径感知 / B. 简单直线转弯 | **B** | 需求明确 |
| D2 | 航点数量上限 | A. 20 / B. 40 / C. 100 | **B** | 1 页 Flash 足够，平衡容量与复杂度 |
| D3 | 采点方式 | A. 自动生成 / B. 手动采点 | **B** | 先做手动，自动方案作为进阶 |
| D4 | 校准方式 | A. 运动方向法 / B. 起点约束法 | **B** | 开机即可校准，无需运动 |
| D5 | 起点约束 | 接受/不接受 | **接受** | 每次开机必须停在第一个航点，面朝第二个航点 |
| D6 | Flash 分区 | A. 与 Ins.c 共享 / B. 独立页 50/51 | **B** | 避免与现有分区冲突 |
| D7 | 导航计算位置 | A. 4ms ISR / B. main while | **B** | ISR 中做重计算会阻塞其他中断 |
| D8 | 数据同步机制 | A. 关中断 / B. 双缓冲+标志 / C. 互斥锁 / D. 乒乓缓冲 | **D** | 指针交换天然原子，无需关中断 |
| D9 | 方位角滤波 | A. 无 / B. 普通 LPF / C. 环形 LPF | **C** | ±180° 边界处普通 LPF 会走远路 |
| D10 | 到达判定 | A. 单一阈值 / B. 滞后阈值 | **B** | 防止在航点附近反复触发 |
| D11 | 漂移修正 | A. 不修正 / B. GPS 方向修正 | **B** | IMU 漂移 5 分钟可达 5-10° |
| D12 | 编码格式 | A. UTF-8 / B. GBK | **B** | 项目统一编码为 GBK |
| D13 | 合并冲突策略 | A. 保留 HEAD / B. 保留 other 分支 | **B** | other 分支功能更完整（turn_mode 5/7、40ms 遥测） |
