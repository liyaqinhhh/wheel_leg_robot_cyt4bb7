# 电机不对称校准说明

## 问题背景

在测试惯导模式4和5时，发现车辆在 `turn_mode=3`（走直线模式）下存在系统性偏航误差：
- 目标偏航角：0.0°
- 实际偏航角：从 -0.20° 漂移到 15.00°（10.16秒内）
- 偏航角漂移率：约 1.5°/秒

## 根本原因分析

### 1. 电机不对称
从遥测数据 `telemetry_turn_test_20260610_225051.csv` 分析：
- 左电机平均值：-64.8
- 右电机平均值：65.7
- **电机差值：130.5 单位**

右电机输出比左电机高 130.5 单位，导致车辆持续向左偏转。

### 2. PD控制器限制
当前偏航角PID控制器参数：
```c
float erect_Angle_Yaw_2[4] = {1.7, 0, 2, 0}; // KP=1.7, KI=0, KD=2
```

**问题**：积分项（KI）被禁用，PD控制器无法消除稳态误差。

### 3. 理论计算
稳态误差 = 电机不对称力矩 / KP = 14.2 / 1.7 ≈ 8.4°

实际测量：8.62°（理论计算与实际吻合）

## 解决方案

### 方案选择
经过对比分析，选择**方案2：电机不对称校准**，原因：
1. 不影响PID控制稳定性
2. 实现简单，易于调试
3. 可根据实际测试数据动态调整

### 实现方法

#### 1. 添加校准参数
在 `small_driver_uart_control.h` 中声明：
```c
extern float motor_asymmetry_offset;
```

在 `small_driver_uart_control.c` 中定义：
```c
float motor_asymmetry_offset = 65.25f;
```

#### 2. 计算校准值
```
motor_asymmetry_offset = (右电机平均值 - 左电机平均值) / 2
                       = (65.7 - (-64.8)) / 2
                       = 130.5 / 2
                       = 65.25
```

#### 3. 应用校准补偿
在 `small_driver_set_duty()` 函数中：
```c
// 应用电机不对称校准补偿
int16 left_duty_compensated  = left_duty_1 + (int16)motor_asymmetry_offset;
int16 right_duty_compensated = right_duty_1 - (int16)motor_asymmetry_offset;
```

**补偿原理**：
- 左轮增加补偿（+65.25）
- 右轮减少补偿（-65.25）
- 总补偿量：130.5 单位

## 使用说明

### 1. 默认值
当前默认值：`motor_asymmetry_offset = 65.25`

### 2. 调整方法
根据实际测试结果，可以在代码中直接修改：
```c
float motor_asymmetry_offset = 65.25f; // 根据实际测试调整
```

### 3. 验证方法
1. 启动车辆，进入 `turn_mode=3` 模式
2. 观察偏航角是否稳定在目标值附近
3. 如果仍有偏移，根据偏移方向调整校准值：
   - 向左偏移：增加 `motor_asymmetry_offset`
   - 向右偏移：减少 `motor_asymmetry_offset`

### 4. 精细调整
建议调整步长：5-10 单位
- 如果偏航角漂移率 > 0.5°/秒，调整 10 单位
- 如果偏航角漂移率 < 0.5°/秒，调整 5 单位

## 预期效果

### 补偿前
- 电机差值：130.5 单位
- 偏航角漂移：1.5°/秒
- 稳态误差：8.6°

### 补偿后（预期）
- 电机差值：≈ 0 单位
- 偏航角漂移：< 0.1°/秒
- 稳态误差：< 1°

## 注意事项

1. **校准值依赖硬件**：不同车辆可能需要不同的校准值
2. **定期校准**：建议每次更换电机或驱动器后重新校准
3. **温度影响**：电机性能可能受温度影响，极端环境下可能需要重新校准
4. **安全范围**：校准值建议在 -200 到 +200 范围内，超出范围可能表示硬件问题

## 其他解决方案对比

### 方案1：启用积分项
```c
float erect_Angle_Yaw_2[4] = {1.7, 0.1, 2, 0}; // KI=0.1
```
**优点**：自动消除稳态误差
**缺点**：可能引入积分饱和，影响系统稳定性

### 方案3：增加KP值
```c
float erect_Angle_Yaw_2[4] = {3.0, 0, 2, 0}; // KP=3.0
```
**优点**：减少稳态误差
**缺点**：可能引起系统振荡，降低稳定性
