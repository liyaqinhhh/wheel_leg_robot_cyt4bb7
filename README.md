# 轮腿机器人控制系统 (CYT4BB7)

基于 **Infineon TRAVEO T2G CYT4BB7** 双核 MCU 的轮腿机器人嵌入式控制工程，使用 **IAR Embedded Workbench** 编译，底层驱动基于 **逐飞科技 (Seekfree)** 开源库。

## 硬件平台

| 项目 | 规格 |
|------|------|
| MCU | Infineon CYT4BB7 (双核 Cortex-M7, 250MHz) |
| IMU | IMU660RA (六轴姿态传感器) |
| GNSS | 外接 GPS 模块 (逐飞 zf_device_gnss) |
| 显示 | IPS200 彩色液晶屏 |
| 通信 | LoRa3A22 + 无线串口 (遥控) |
| 测距 | TOF DL1B 激光测距 |
| 电机 | 小驱电机驱动板 (UART 控制) |
| 舵机 | 四路腿关节舵机 (PWM 控制) |
| 开发环境 | IAR Embedded Workbench 9.40.1 |

## 核心模块说明

### ControlPart — 控制核心

控制系统的核心模块，包含平衡控制、姿态解算、遥控通信等关键功能。

| 文件 | 功能 |
|------|------|
| `PID.c/h` | 多环 PID 控制器：角度环、角速度环、速度环、转向环、增量式 PID |
| `Interrupt.c/h` | 多级定时中断调度 (1ms/2ms/4ms/8ms/16ms/40ms)，各频率执行不同控制任务 |
| `servo.c/h` | 四路腿关节舵机控制、跳跃动作、平衡补偿、高度切换 |
| `imu660.c/h` | IMU660RA 姿态数据处理、欧拉角获取 |
| `ekf.c/h` | 扩展卡尔曼滤波 (EKF)，姿态融合 |
| `kalman.c/h` | 卡尔曼滤波器 |
| `remote_control.c/h` | 遥控器协议解析 (自定义帧协议，支持摇杆/模式/高度/急停) |
| `yaokong.c/h` | 遥控数据映射与运动控制逻辑 |
| `AI_Pid_Tuner.c/h` | AI 辅助 PID 参数自整定 |
| `Buzzer.c/h` | 蜂鸣器控制与状态提示音 |
| `Math_Advanced.c/h` | 高级数学运算 (矩阵运算等) |
| `matrix.c/h` | 矩阵运算库 (EKF 依赖) |
| `small_driver_uart_control.c/h` | 小驱电机驱动板 UART 通信 |
| `Init.c/h` | 系统全局初始化 (传感器/驱动/PID/滤波器/GPS) |

### GpsNav — GPS 导航

基于 GNSS 的自动导航系统，支持航点采集、路径规划和自动循迹。

| 文件 | 功能 |
|------|------|
| `gps_nav.c/h` | 导航状态机 (IDLE→校准→导航→到达→完成)，双缓冲转角输出，低通滤波 |
| `gps_waypoint.c/h` | 航点管理 (采集/存储/Flash 持久化/遍历)，最多 40 个航点 |
| `gps_calibration.c/h` | IMU-GPS 偏差校准 |

导航状态流转：

```
IDLE ──► CALIBRATING ──► NAVIGATING ──► ARRIVED ──► COMPLETE
  │           │               │           │
  └──(停止)───┘               └──(平滑/超时)┘
```

### ins — 惯性导航

基于 IMU 的航位推算 (Dead Reckoning) 系统，支持记录/循迹/分段导航。

| 文件 | 功能 |
|------|------|
| `Ins.c/h` | 惯导主模块：实时坐标更新、目标距离/方位计算、状态机 (记录/循迹/编辑/运行) |
| `ins_core.c/h` | 核心算法：坐标累积、方向余弦计算 |
| `ins_interface.c/h` | 接口层：与 PID 控制系统的数据交互 |
| `ins_segment.c/h` | 分段惯导：手动编辑航段、分段运行 |
| `ins_track.c/h` | 轨迹跟踪算法 |

### Menu — 菜单系统

OLED/IPS 屏幕上的交互菜单，支持参数查看与 Flash 读写。

### VersionPart — 显示模块

IPS200 屏幕驱动与图像显示，实时展示机器人状态 (姿态角、坐标、GPS 信息等)。

## 控制系统

### PID 控制架构

采用**串级 PID** 控制方案，内外环分层：

```
                 ┌─────────────┐
  目标角度 ──►  │  角度环(外环) │ ──► 角速度设定值
                 └──────┬──────┘
                        │
                 ┌──────▼──────┐
  角速度 ──────►│ 角速度环(内环)│ ──► 电机/舵机输出
                 └─────────────┘
```

- **俯仰通道**：角速度环 → 角度环 → 速度环 (三级串级)
- **横滚通道**：角速度环 → 角度环
- **偏航通道**：角速度环 → 角度环 (多组参数，适配不同转向模式)
- **位置/高度**：增量式 PID 控制
- **转向**：支持 7 种转向模式 (PID/通道/偏航角/视觉/GPS/原地旋转/惯导)

### 中断调度

| 频率 | 主要任务 |
|------|---------|
| 1ms | IMU 偏航角积分、编码器累加、基站计时 |
| 2ms | 跳跃控制、按键扫描、AI 数据、IMU 数据读取、角速度环 PID |
| 4ms | 互补滤波、角度环 PID (外环)、转向 PID、模式切换 |
| 8ms | 步态高度控制、横滚平衡环 |
| 16ms | 速度环 PID (外环)、惯导坐标更新 |
| 40ms | 遥控逻辑、超时检测、偏航漂移补偿 |

### 运动学

四腿关节采用**逆运动学**求解，将末端笛卡尔坐标 (X, Y) 映射为各关节角度：

- 腿部连杆参数：L1=6cm, L2=9cm, L3=9cm, L4=6cm, L5=3.5cm
- 支持跳跃动作 (四阶段：蓄力→起跳→展腿→收腿)
- 支持单腿高度切换 (高低位姿态)

## 操作说明

### 按键功能

| 按键 | 功能 |
|------|------|
| KEY_1 短按 | 采集当前 GPS 坐标为航点 (需 ≥4 颗卫星锁定) |
| KEY_2 短按 | 开始/停止 GPS 导航 (IDLE ↔ 导航态切换) |
| KEY_3 短按 | 惯导记录模式下记录当前坐标 |

### 安全保护

- 电机速度超限保护 (±3000 阈值)
- 姿态角超限保护 (±7000 阈值)
- 遥控信号超时安全停车 (500ms)
- GPS 信号丢失自动停止导航 (5s 无数据)

## 编码规范

- `.c` / `.h` 文件使用 **GB2312** 编码 (IAR 编译器要求)
- 其他文件 (`.md` / `.py` / `.json` 等) 使用 **UTF-8** 编码
- AI 生成 .c/.h 文件后必须执行：`python tools/encoding_converter.py wrap <filepath>`
